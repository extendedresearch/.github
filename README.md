# .github

This repository holds the Extended Research organization profile.

| Path | Contents |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The page shown at [github.com/ExtendedResearch](https://github.com/ExtendedResearch) |
| [`profile/assets/banner.svg`](profile/assets/banner.svg) | The banner at the top of that page. Its signal traces are synthetic and illustrative, not recorded data |
| [`scripts/build-banner.mjs`](scripts/build-banner.mjs) | Regenerates the banner: `node scripts/build-banner.mjs`. Colours follow the Orbit palette in the style guide |

Community health files placed at the root of this repository, such as
`CONTRIBUTING.md` or issue templates, apply to every repository in the
organization that does not define its own.

Shared writing guidelines, the contributor handbook, and templates live in
[commons](https://github.com/ExtendedResearch/commons).
