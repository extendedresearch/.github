Extended Research builds open-source tools for studying human and machine
intelligence together. The tools run several instruments in one study, record
what they capture with timestamps and losses accounted for, store it in a form
model training can read directly, and run trained models on live data as it is
recorded. The work is intended for research in psychology, neuroscience,
neuroAI, human-centred AI, clinical outcomes, rehabilitation, and biomechanics.
